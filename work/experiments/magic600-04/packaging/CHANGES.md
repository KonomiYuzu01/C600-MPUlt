# Changes since 0.3 — Magic 600 Cell 0.4 candidate

- Replaced the office-style solving composition with the abstract graphical
  workspace and a shared Solve window. Current, Operation and After show
  separate actual, operation and predicted relations.
- Added mathematical structure names and typed addresses while retaining
  canonical identities, home/current distinctions and existing model labels.
- Integrated orbit-specific editable keymap sets, the compact launchable
  onscreen keyboard, explicit Functions switching, ordered Grip frames and
  matching Twist feedback.
- Connected Macro Base selection, fixed-step editing, whole-effect inspection,
  candidate comparison, saved worksheets and explicit insertion. Scores remain
  separate from protection permission and never execute a macro.
- Added explicit place/orient/buffer/orbit completion intentions, source-bound
  residual and invariant evidence, manual finite endgame families and exact
  source/destination reference variants. Full collateral remains visible.
- Preserved per-orbit drafts and selected macro revisions across explicit
  cross-orbit work, including locked Next transitions. Completion protection,
  journal ownership and recovery continue through the authoritative Session.
- Added isolated portable assembly with exact model/source/proof integrity,
  separate versioned data by default and no runtime compiler or developer
  fixture startup.
- Connected shared Session New/Resume, timers, staged scramble, recoverable
  reset and journal-bound completion summaries. Added C600/MPUlt log file
  export and explicit check/import, plus versioned keymap file export/check/apply.
- Restored explicit controls for framework visibility, adaptive motion and the
  retained MPUlt size, field-of-view and lighting settings, preserving Instant
  Turn. Native control mappings, rejection, focus and reset geometry have been
  checked; final package acceptance remains pending.

This change list describes a release candidate awaiting acceptance. Final continuous native
acceptance, packaging compatibility, scaling and recording remain separate
delivery gates; this document does not mark them complete.

Performance optimization is scheduled for the next iteration.

Changing a protection policy invalidates an earlier preview. Execute can remain
clickable, but the stale request is rejected before a transaction. Cancel the
old preview, then check and preview again under the current policy.

Use Solve's Prepare page to view a located conflict's identity and current
position. Automatic page navigation or graphical highlighting is not guaranteed.

The accompanying acceptance report records completed checks, reused evidence
and any remaining delivery requirements. Recording and reviewed English-only
subtitles remain a separate delivery step.
