# Versioned keybinding files — bounded handoff

The Magic600-keymap schema 1 exports the existing saved grips/twists/commands/banks override record, bound to the exact model. It excludes cap captures, ordered frames, macro recipes, bank names, active-set selection and solving state. Import explicitly replaces the whole saved override record; omitted values inherit current defaults. Existing Ctrl aliases and valid null sections retain their representation. Unsupported historical sentinel data is rejected without reinterpretation or omission.

Central helpers in keymap_catalog.py: export_keymap(model_id, bindings, allowed_command_ids, bank_ids), inspect_keymap(text, model_id, current_bindings, allowed_command_ids, bank_ids), import_keymap(text, basis, model_id, current_bindings, allowed_command_ids, bank_ids). bank_ids maps canonical bank IDs to their active Grip slot count; command-only sets use zero. The confirmation basis binds the exact imported text digest, model and previous complete saved record. Root owns atomic persistence through the existing adapter.

Native production seams in ExperimentKeyboard.cs are ExportKeymapFile(path) and ShowKeymapFileImport(path), both Task<bool>; the ordinary Save/Open dialogs delegate to them. RegisterKeymapFileCommands registers the two editable actions. Functions adds Ctrl+Alt+I/E for keymaps and Ctrl+Alt+O/L for Session logs; existing occupied shortcuts and legacy Session routes remain intact. Full validation errors use the existing feedback, and rejected Apply retains the confirmation window. Both read paths retain authoritative receipts across the Stop barrier.
