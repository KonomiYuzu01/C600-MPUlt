# CurrentScore integration — 2026-09-16

## Scope and limiting interaction

The existing complete-operation review had exact effects, goals and protection, but
the solver could not inspect their combined current usefulness or locate the objects
behind a reason. This change extends that review and the existing Solve Protection
page. It adds no solver, candidate search, parallel Session, or endgame workbench.

CurrentScore uses the accepted deterministic weights and exact full-operation
evidence. It distinguishes benefit, preparation, conflict and missing evidence.
Recommendation never stages or executes an operation. Unsupported reference maps
remain Unknown. Displaced-piece orientation diagnostics count for Gtheta without
being presented as already-placed orientation residuals.

Reasons carry canonical identities and actual-before positions. The native scene
marks inspected identities with corner marks distinct from Current/Next. A reason
opens the complete Operation view, temporarily hides the obstructing Solve window,
and preserves its page and working context for return. Existing editable key sets
provide three reason routes; the independent Functions entry remains unchanged.

## Independent findings and corrections

- A generic composition could bypass missing-reference evidence: the reference gate
  now applies before role-specific matching.
- Different verified Before/After frame certificates could be combined: the paired
  chart certificates must agree.
- Block/FinishOrbit reasons could point to an unrelated Current: evidence now comes
  from the actual changed goal predicates.
- Strict rejection of a cancelling operation had empty net support: the existing
  prefix checker now records actual first-violation positions and total counts.
- A requested cycle member was incorrectly compared with the canonical cycle anchor:
  projection echoes the original requested position and checks it independently.
- An inspected position with no net change now uses a static position marker and
  empty edges; it does not increase cycle/orientation counts or imply a legal move.
- The first reason shortcuts collided with Functions and displayed internal key
  codes: defaults now use vacant keys and the existing onscreen-key formatter.
