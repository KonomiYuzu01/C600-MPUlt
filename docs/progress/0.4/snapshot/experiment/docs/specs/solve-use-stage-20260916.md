# Solving-use classification and continuous Solve — 2026-09-16

## Current limiting factor

The library's saved orbit group is presented as though it describes solving use,
while the available exact facets describe effects. These are different questions.
In native baseline `postapproval-g2-20260916-085608`, Macro Base, Operation and
Keyboard also obscure the working geometry when opened together. This slice
connects trustworthy use discovery to the existing explicit operation workflow.

## Confirmed contract

Use classification estimates which orbit(s) a solver would usually use a macro to
solve. Full affected-orbit sets, certified Star, per-edge orientation-neutral
single piece cycles, stationary orientation effects and collateral are evidence
inputs, not substitutes for the final purpose. Multiple memberships and Other
are allowed. Missing evidence remains distinguishable from a general-purpose macro.
Saved library groups and human notes are preserved; none becomes a proof.

Intrinsic structure, inferred likely use and current suitability stay separate.
Protection changes do not silently change structural membership. No opaque score,
automatic macro choice, setup search or execution. Complete Prepare/Macro/Cleanup
protection remains the authoritative execution check, including hidden objects.

Pure Piece Cycle means exactly one nontrivial piece cycle within the orbit and
every mapped edge agrees with an explicit independent ordered slot reference.
All other slots in that orbit must be fixed. Collateral is reported separately.
Existing positional-three-cycle and eventual frame return cannot substitute.
Missing reference is visible; it is not silently supplied by the tested macro.

   report. Source cap + ordered corners and selected destination Grip/frame are
   distinct explicit inputs. Prove exact incidence and legal generator mapping;
   do not change assets or infer a 20-cell piece frame from a four-corner cap frame.

## Rejected alternatives

Sorting by largest support invents purpose. Copying the entire Hub creates competing
state. Shrinking its present fixed geometry clips content. A remote model in every
classification would add latency, privacy and nondeterminism without evidence of
benefit; use explainable local inference over exact facts in this slice. The existing
Agents API remains advisory development review, not the game's classifier.

## Acceptance and rejection conditions

- Real retained Star and its inverse receive justified orbit use. Ordinary single-
  orbit orientation work remains findable; many-cycle/collateral examples do not
  acquire false Pure/Star status. Imported proof claims are not trusted.
- Protection changes affect suitability, not intrinsic use. Missing or evicted
  facts remain unknown. Certification precedes display truncation. No state change
  occurs from classification/filtering; IDs survive sorting and empty results.
- One native Solve window supports select → Add → full check → preview → explicit
  execute; tabs do not switch bank, Next, draft, reference or pending preview.
- Keep all existing distinct catalogue, work sheet and operation capabilities.
  Preserve Stop acknowledgement barrier and actual operationStrip focus guard.
- Check same E1 state and 1280×720 logical desktop, long names, empty results,
  dense steps, focus restoration, placement restoration and narrow window. Report
  actual scaling/capture method; no unmeasured GPU/human performance claims.
- Independent specification and code review precede final fresh native evidence.
