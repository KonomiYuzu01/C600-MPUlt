## Problem and decision

Existing exact comparison is only an unbound result; saving R^-1 / Macro / R loses its source. The native transformation command gives no clear saved-result path. A solver cannot reliably inspect a chosen variant and deliberately carry it into the existing operation.

Extend the current Macro details tool with explicit comparison and variant creation. Keep the catalogue, operation draft and Session boundaries. A separate large workbench or automatic library grouping would add scope and navigation without resolving this concrete break.

## Invariants

- Comparison explicitly names two canonical records; no default second choice. Bind results to model, both identities, versions and exact recipes. Whole-action equality/inverse and orbit-local equality are separate, including both-inactive cases. Original costs, words and prefix motion remain separate. Net equality is never a protection certificate.
- Inverse and user-specified legal-word conjugation create a new independent macro. Preserve the existing derived_from format (source ID/version, kind, and explicit R/convention where applicable), the source itself and its original steps. No saved-format migration or imported proof trust.
- This R is a finite chosen legal primitive word. Chronological R^-1 / Macro / R is not a certified geometric reference map. No search, automatic macro selection, target retargeting or automatic insertion.
- Native requests bind source identity/version/recipe and, for R, the exact displayed current R. Changed source/R must reject without mutation. Fully validate before saving; failed persistence must not publish partial in-memory creation.
- Saving does not change selected macro, draft, Current, locked Next, bank, mechanical state or pending preview. Show returned canonical created ID and a separate Select saved macro action. Comparison and closing do not cancel a pending preview. Existing operation context guards decide whether later explicit insertion needs a new review.
- Preserve the source record's saved orbit group; it is metadata, not a certificate of full support. Validate resulting total recipe bounds and observe cancellation before publication. Exact R mismatch includes a different word with the same net effect. A late comparison result cannot appear under a changed pair or disposed dialog.
- Keep compact existing Macro details / Current–Next–protection context. Explanations belong in details; preserve familiar labels and keyboard routes, visible focus and input guards. Shared Macro bank gets appended routes without moving existing keys.
