## B4-12 status and next work

B4-12 remains **not passed / deferred** from 0.4 into the 1.0 Architecture workstream. Its original thresholds and correctness requirements are unchanged. Optimization and verification resume after the planned device change; hardware causality has not been established and a hardware upgrade is not a guaranteed remedy.

V11.1 defines bounded UI, response-processing, engine and presentation work packages, preserved safety/permission/durability boundaries, small-sample screening and final acceptance on a frozen candidate. Only matching evidence against all original criteria closes the item. Current-release performance wording remains: "Performance optimization is scheduled for the next iteration."

## Revision scope

A3 supersedes A2's hardware-exception release wording with the user's explicit deferral decision. It preserves the integrated A2 architecture, historical source observations and undecided D-1 through D-7. Technical proposals remain proposals.

This publication contains documents only. It is not an application release, an implementation approval, a passing performance certificate or an update to the current executable. Private diagnostic logs, personal sessions and raw acceptance evidence are excluded. Other current-release correctness, desktop, package and recording obligations remain in force.
